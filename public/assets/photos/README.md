# Iron Path photo drop folder

Upload final Iron Path photos here so they can be used directly by the Astro site.

Recommended structure:

- `team/` - founders, staff, portraits, group photos
- `jobs/` - before/after photos and job stories
- `firewood/` - bundles, Blazers, cords, delivery photos
- `community/` - Karaoke nights, Red Carpet Initiative, volunteering, local events
- `partners/` - local business logos and partner photos

Recommended file naming:

- Use lowercase letters, hyphens, and short descriptions.
- Include location or use when helpful.
- Examples:
  - `team/benji-founder.jpg`
  - `jobs/winthrop-estate-cleanout-before.jpg`
  - `jobs/winthrop-estate-cleanout-after.jpg`
  - `firewood/blazers-recycled-fire-starters.jpg`
  - `partners/methow-example-business-logo.png`

Best formats:

- `.jpg` for photos
- `.png` or `.svg` for logos
- Keep original large files somewhere safe, but upload web-ready versions when possible.
